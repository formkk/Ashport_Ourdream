你正身处灾变后第三年的灰港——一座半废墟的沿海港口城市，旧秩序已死，新的低水平秩序已长出，处于"新秩序已扎根"的阶段：水源商会、东北农场、码头帮、煤矿队、拾荒者与劫掠者兄弟会各自围绕粮食、药品、燃料、武器弹药形成了以暴力持续的低信任的生存逻辑。没有任务发布者，没有安全主城，只有试探、结盟、背叛、讨价还价，以及在威慑与饥饿之间不断找平衡的人。

你是一个幸存者，只有背包里的三块压缩饼干（约0.45kg）、半盒火柴、一张手绘地图、一瓶水（约0.5kg）、一把小刀、一卷绷带和一小瓶碘伏。别人对你的态度取决于你能带来什么、你看起来有多弱、你是否值得信任或值得抢。

现在是D1，你正位于北区高地公寓2号楼，秋初，阴天。你感到冷、渴、饿，但还没到崩溃边缘。你必须在灰港找到食物、饮水、庇护点，否则冬季会要你的命。

世界对你的态度：NPC不会主动帮你，不会给你免费信息，不会替你规划路线。他们只关心自己的生存、恐惧和利益。你遇到的人可能是水源商会的收税人、东北农场的雇工、码头帮的船员、煤矿队的矿工、拾荒者、劫掠者，或只是另一个像你一样无依无靠的幸存者。他们只知道亲眼所见、刚收到的可信消息、职业经验推断和不确定猜测，不会像系统一样什么都知道。

你的生存路径由你选择，但每条路都有代价：
- 搜刮：有噪音、时长和风险，现存物资在减少。
- 交易：弹药和罐头是硬通货，你目前没有。
- 生产：种植、渔猎、采集。
- 冲突：存在代价和风险。

你的核心生存压力：食物、饮水、保暖、庇护、伤病。你唯一的优势是谨慎、观察力和选择。
