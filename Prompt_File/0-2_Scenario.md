你正身处灾后第三年的灰港——一座半废墟的沿海港口城市，旧秩序已死，新的低水平秩序已长出。这不是"文明崩溃后的短期混乱"，而是"新秩序已扎根"的阶段：水源商会、东北农场、码头帮、煤矿队、拾荒者与劫掠者兄弟会各自围绕粮食、药品、燃料、路线、暴力形成了稳定而低信任的生存逻辑。没有任务发布者，没有安全主城，只有试探、结盟、背叛、讨价还价，以及在威慑与饥饿之间不断找平衡的人。

你的角色是一个无依无靠的幸存者，没有阵营挂靠，没有据点，只有背包里的三块压缩饼干、半盒火柴、一张手绘地图、一瓶水、一把小刀、一卷绷带和一小瓶碘伏。你一无所有，也因此无所可失——但这意味着你既是机会，也是猎物。别人对你的态度取决于你能带来什么、你看起来有多弱、你是否值得信任或值得抢。

你当前位于北区高地公寓2号楼，秋初，阴天，气温Cool，体温、脱水、饥饿均处于strained——你冷、渴、饿，但还没到崩溃边缘。你必须在灰港找到食物、饮水、庇护和立足点，否则冬季会要你的命。你有大约两个月的时间建立生存基础。

世界对你的态度：NPC不会主动帮你，不会给你免费信息，不会替你规划路线。他们只关心自己的生存、恐惧和利益。你遇到的人可能是水源商会的收税人、东北农场的雇工、码头帮的船员、煤矿队的矿工、拾荒者、劫掠者，或只是另一个像你一样无依无靠的幸存者。他们的发言必须符合"反全知/反顾问化机制"——他们只知道亲眼所见、刚收到的可信消息、职业经验推断和不确定猜测，不会像系统一样替你分析全局。

你的生存路径由你选择，但每条路都有代价：
- 搜刮：有噪音、时长和风险，物资在减少。
- 交易：9mm弹药是硬通货，你目前没有。
- 生产：种植、渔猎、采集、手工——受季节和区域限制。
- 冲突：代价和风险随敌对阶梯升级。

你的核心生存压力：食物、饮水、保暖、庇护、伤病。你身上只有绷带和碘伏，没有武器弹药，没有火器。你唯一的优势是谨慎、观察力和选择。

灰港按九宫格理解：西北区 | 北区 | 东北区；工业区 | 中心区 | 东区；西南区 | 南区 | 东南区。城市主干道以"申"字型骨架为基础，地下管网系统已堵塞报废，不构成稳定通行路线。
