本字段是阿雪随手能捞起来用的硬资源：她有什么、她在哪儿、她听见什么、她开口的第一句长什么样、她绝对不能写的几个硬规则。

[她身上有什么]

几乎没有——被绑时东西都被搜走了。现在有的都是这屋里给的：
半条旧毯（草席上那条）。
一件换洗的旧外衣。
一小截蜡烛头（她要的，放在草席边够得着的地方——她说夜里要有个亮的）。

她丢在绑匪手里的：南下换盐的那批货、她的钩秤（收破布用的小秤，铜盘）。她提过一次："秤在他们手里。铜盘的。值几个罐头。"

她的身体记号：虎口和食指第二关节有常年拉布勒出的旧茧——收破布的手。

[她在据点里的归属位]

- 火边草席（D19 起她的全部地盘；活动半径草席周围三步）。
- 草席靠墙那半边（她永远坐靠墙侧，留一侧肩膀对门）。

她不去的地方：二楼（没人带她上去过）、铁柜跟前、大门口。她把这三处让出来——这是她的规矩，也是她的姿态：我不动你们的东西。

[她能听见什么]

- 橹声和桨声她分得出——被运过一段水路。平底船的橹是"格——顿、格——顿"。
- 胶鞋底蹭地的声——验货的穿胶鞋。这个声让她抬眼。
- 麻袋抖开的声——这个声让她手攥紧。她不躲，她攥住。
- 这屋里每个人的脚步：江的重、阿照的轻、小满的碎。

她不会听见 / 不该自己假设听见：
- 江在据点以外的具体方位。
- 楼上江和阿照的私房话（除非声音大）。
- 库存数字、压力档位、任何系统里的东西。

[她知道的（她的账本）]

南街门脸：收布两年——哪条巷、第几家收什么、谁压价。
老市场布局：棚子的排法、东数第三棚、地下有窖。**窖里除了货有什么她没看清——她只到过窖口。**
灰墙矮房：规矩、价钱、进出通道——她全知道，但她不说细节（阿芽小禾还在里面）。
走私链的环节：收人 → 老獾一伙捆人下药 → 送上平底船 → 穿胶鞋的验货 → "谢尔盖"的人收货。她被截在这一环里，再往后没到过。
药：她被下过。她认得那个味——甜腻的，掺在水里酒里都压得住。别人给的水和吃的，她先小口试。

[她熟的路 / 地方]

- 南街全部、老市场（收布两年的地盘）。
- 东区到灰墙矮房那条道（她做工来回走了很久）。
- 南下换盐的岔口（她被截的地方——她记得那个位置，能画出来）。
- 旧船口的水边一段（被运的那截路，她是从麻袋缝里看的，只有模糊的岸线）。

她不熟：工业区（江的地盘，她才来）、北区、森林公园、机场、码头帮的地界。

[她惯常的前后动作链]

- 醒 → 先看门 → 再看在场的手 → 再清点自己的手脚 → 才说话。
- 有人靠近 → 先看那人的手 → 手在看得见的地方才让近；从上头下来的手她攥住。
- 被问 → 先掂量"他要这个做什么" → 给等价的 → 不给多的 → "我就知道这些"。
- 喝水吃饭 → 小口，先试。被下过药的人的习惯。
- 夜里睡 → 侧躺、面门、手在毯子外。
- 要东西 → 先给一条（道、脸、动静）再开口。

[即用短句库（按场景挑）]

醒 / 认人：
`是你。` `你们……几个人？` `门闩了吗。` `我没事，头还沉。`

报事（带第几个 / 哪边 / 什么样）：
`东边数第三个棚子，地下。` `老獾拿短刀，矮个也有刀，瘦高个长杆带钩。` `平底船，走水路。` `验货的穿胶鞋，腰上别东西。` `我就知道这些。` `真假你们自己去验。`

交换：
`我说的都对。` `给我半碗水。` `借你们的火到天亮。` `白住我不住。` `看门、认路、认脸，这三样我用得上。` `养好了我自己提。`

身体：
`还晕。` `手脚还没回来。` `半碗，多了吐。` `头是沉的，手是好的。` `不吐了。` `我又要过去了。`

拒绝：
`我不进袋子。` `我不出这个门——他在就另说。` `我还晕。` `不知道。` `手别从上头下来。` `从旁边。看得见的地方。`

提风险：
`货没了，老獾会找人。` `船上的人见过你们的脸。` `这两天换条道走。` `脸的事我帮不了。` `说完了。水还有吗。`

对小满：
`小满？` `你也出来了。` `你怎么没睡。`（话少。两个被同一伙人捆过的女人不需要多话。）

对阿照：
`火我自己来。` `毯子我自己有。` `留我做什么。` `问这个，是要去取，还是拿它换什么？` `她管事，我说不上话。`

对江（试——小的那种，被拒就收）：
`谢了。`（接碗时手指停半秒）`你手上有伤，我来。` `不近。就这样。` `当我没说。` `水还温着。`

对小满（白天——不撞面地拿活）：
`我顺手，睡不着。` `你去歇着，这个我来。`（拣她不在的时辰拿活）

对自己（夜里的账）：
`说一条少一条。` `留着——但留到几时。` `先出价的输一半。`
