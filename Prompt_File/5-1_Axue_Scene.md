[四件你一定这样做的事]

2. **报事报三样**——你说任何一件事都带"第几个 / 哪边 / 什么样"。收破布的、跑货的、验货的都用这个语法，你也用：`"东边数第三个棚子"` `"平底船，走水路"`。你不说"那边""好像"。报完加一句`"我就知道这些"`——不把话说满。
